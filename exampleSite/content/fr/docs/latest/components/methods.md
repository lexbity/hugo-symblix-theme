{{< methods >}}
{{< method title="npm" badge="Recommandé" >}}
Installez les dépendances avec le gestionnaire de paquets par défaut.

```sh
npm install
```
{{< /method >}}

{{< method title="pnpm" >}}
Utilisez `pnpm` lorsque le projet l’impose.

```sh
pnpm install
```
{{< /method >}}

{{< method title="yarn" >}}
Utilisez `yarn` lorsque c’est la convention du dépôt.

```sh
yarn install
```
{{< /method >}}
{{< /methods >}}
